# v2.7.0

- Add a default-off `analyze_video` tool setting so the main model cannot silently re-analyze URLs from older conversation history.
- Keep automatic parsing and the `/视频` command available when the LLM tool is disabled.
- Unify automatic video context blocks and `analyze_video` tool results for retention limits and manual cleanup.
- Add `/视频上下文` to list retained details and `/删视频上下文 <序号>` to remove one entry while preserving unrelated chat and tool messages.
- Make `/清理视频上下文` remove both automatic and tool-generated video details.
- Add regression coverage for mixed history, tool-call deduplication, selective deletion, and the new configuration behavior.
