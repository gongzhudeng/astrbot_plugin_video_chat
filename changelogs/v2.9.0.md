# v2.9.0

- Run local video captioning and STT concurrently so speech recognition no longer adds its full duration after visual analysis.
- Add a configurable STT abandonment deadline that starts with STT but only takes effect after visual captioning completes.
- Keep completed transcripts when visual captioning runs past the deadline, and support `0` to always wait for STT.
- Apply the shared orchestration to direct videos, Douyin, Bilibili without subtitles, and generic local video sources.
