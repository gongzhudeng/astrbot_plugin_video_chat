- Redefine `max_video_context_details=0` as temporary video parsing mode: full video details are available only to the current Provider request and are not written to conversation history.
- Preserve the current user message and normal assistant reply while removing existing full video context blocks from history in temporary mode.
- Pre-persist the current user turn in positive-limit mode so parsed video details survive Provider errors, empty responses, stopped events, and Runner exceptions.
- Keep positive values as the number of recent full video contexts retained, replacing older details with lightweight markers without changing user or assistant text.
- Add `/清理视频上下文` to clear full video details from the current conversation on demand.
- Add focused lifecycle tests and privacy-safe diagnostics for request assembly and history persistence.
